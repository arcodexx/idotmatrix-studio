# Update Log 001: v2.0.0 Studio Overhaul & Independence

* **Date**: November 2026
* **Version**: `2.0.0`
* **Author / Maintainer**: Utkarsh Bhati (`@arcodexx`)
* **Status**: Complete & Released to `main`

---

## 1. Background & Context

The project originated as a fork of `aviwad/idotmatrix-swift`. Over several months, multiple major feature branches were developed:
* `enhance/music-integration`: Real-time Spotify album art streaming.
* `feat/scheduler`: Daily automation scheduler with time slots.
* `feat/pixel-art`: 32×32 pixel art drawing canvas and tools.
* `feat/divoom-api`: Community cloud gallery browser.

With upstream inactive, these feature sets were unified into a cohesive release. However, the original user experience suffered from scattered floating windows, outdated build settings, and lack of visual feedback.

---

## 2. Key Architecture & Feature Deliverables in v2.0.0

### A. Dual-Layer Interface Architecture
1. **MenuBar Quick View (`MenuBarQuickView.swift`)**:
   - Streamlined into a 295px popover.
   - Live hardware status dot and connection toggle icon buttons.
   - Real-time mini virtual LED mirror.
   - Smooth brightness slider.
   - 4 quick preset pills: `Clock`, `Music`, `Color`, `Effects`.
   - 8 pure saturated preset colors (`#FF0000`, `#00FF00`, `#0000FF`, `#FFFF00`, `#00FFFF`, `#FF00FF`, `#FF7300`, `#FFFFFF`) + custom ColorPicker.
   - One-click shortcut to launch the full Studio workspace.
2. **Dedicated Studio Workspace (`StudioView.swift`)**:
   - Unified `NavigationSplitView` workspace replacing disparate floating windows.
   - Sidebar tabs: **Live Display**, **Pixel Art Editor**, **Divoom Community Library**, **My Assets**, **Daily Scheduler**, **Settings**.
   - Auto-adjusting window dimensions (980×660) managed by `StudioWindowManager.swift`.

### B. Hardware-Accurate Virtual Matrix Engine (`VirtualMatrixView.swift`)
- Reusable 32×32 LED grid simulation rendered using SwiftUI `Canvas` and `TimelineView(.periodic)`.
- Real-time mirror of the physical display:
  - Ticking digital clock with blinking colons.
  - Streaming Spotify album artwork downsampled to 32×32.
  - Saturated full-screen solid fills.
  - Animated thumbnails for built-in hardware lighting presets (`1effect` through `7effect`).

### C. Pixel Art Studio Overhaul (`PixelArtEditorView.swift`)
- Canvas locked to an optimal 384×384 (12pt per cell) wrapped in a responsive `ScrollView`.
- Resolved an issue where drawing tools (Pen, Eraser, Eyedropper, ColorPickerRing, Fill Bucket, Clear) were pushed off-screen on smaller displays.
- Removed redundant floating window asset launchers.

### D. Xcode 16 / Swift 6 Modernization
- **CompactSlider Migration**: Upgraded dependency from `1.2.1` to `>= 2.0.0`. Resolved `LinearGradient` opacity ambiguity errors under Swift 6. Refactored all slider implementations in `Content.swift` to version 2.x label hierarchy.
- **Explicit Build Phases**: Resolved linker failures (`Undefined symbol: _main`) by explicitly mapping all 39 source files into `PBXSourcesBuildPhase` and resources into `PBXResourcesBuildPhase`.
- **Dynamic Binary Packaging**: Set `PRODUCT_NAME = "iDotMatrix Studio"`. Dynamically resolved `divoom_convert.py` within `Bundle.main.resourceURL`.

### E. Divoom Library UX & Security Hardening
- Scrubbed all personal credentials from git history.
- Added user onboarding screen with one-click links to the Divoom website, iOS App Store, and Google Play.
- Added credentials persistence via `UserDefaults` and a gallery "Sign Out" button.

### F. Rebranding & Repository Independence
- Officially detached from upstream fork network via GitHub Settings to become an independent root repository (`arcodexx/idotmatrix-studio`).
- Updated bundle identifier to `com.arcodexx.idotmatrix-studio`.
- Added official MIT License with attribution to Avi Wadhwa and Utkarsh Bhati.
- Overhauled `README.md` with modern badge headers, architecture diagrams, and comprehensive documentation.
